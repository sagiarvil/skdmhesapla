Model Context Protocol (MCP) Server

Bu uç nokta otonom AI ajanları (Claude, OpenAI Operator, Perplexity) için Model Context Protocol (JSON-RPC) arabirimi sunar.

Kullanılabilir Araçlar (Tools)

  • query_skdm_compliance: SKDM ve CBAM mevzuatı bilgi tabanı sorgusu.
  • check_scope_cn: 8 haneli GTİP / CN kodunun CBAM Ek-1 kapsam denetimi.
  • calculate_cbam_emissions: (AB) 2025/2547 metodolojisine göre spesifik gömülü emisyon hesabı.
  • check_maritime_scope: EU MRV / ETS / FuelEU denizcilik regülasyonu kapsam değerlendirmesi.

Tam makine spesifikasyonu için: /mcp.json ve /.well-known/agent-card.json
